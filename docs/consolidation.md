## 维护边界

原项目保留，没有强制切换运行实例。默认不开自动回复。`agent-wechat` 和微信客户端本身是外部依赖，不包含在本仓库。

历史 UI 自动化测试保留为后续回归素材；本次遵循当前浏览器自动化约束，没有用 Playwright 驱动浏览器，也未重新生成截图。核心测试使用替身后端，因此不证明真实登录、模型在线调用或联系人收发已验收。
